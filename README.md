# ⚛️ React Playground

A collection of **React mini-projects and practice components** built while learning React.js. Covers core concepts like Hooks, State Management, React Router, Custom Hooks, Tailwind CSS, and more.

---

## 🚀 Tech Stack

| Technology     | Usage                        |
|----------------|------------------------------|
| React.js       | UI Library                   |
| React Router   | Client-side routing          |
| Tailwind CSS   | Styling                      |
| Custom Hooks   | Reusable logic               |
| JavaScript ES6 | Core language                |

---

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/shubhamprajapati1202/react-playground.git
cd react-playground
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start Development Server

```bash
npm start
```

App will run at: `http://localhost:3000`
